# C13 — Planos de ação de performance

Fecha o ciclo `KPI → contexto → tendência → explicação → ação`. Um driver do Dashboard pode originar uma ação governada com organização, período, moeda, linha de performance, responsável, prazo e prioridade. O workflow é `Aberta → Em curso → Concluída/Cancelada`; conclusão exige evidência, registos não podem ser eliminados e todas as transições entram no audit trail.
